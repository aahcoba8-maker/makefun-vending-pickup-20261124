# Vending Machine Pickup Line

A one-line entry for the make.fun contest "One Line, One Minute: The Vending Machine Pickup Line Contest" — one pickup line, as if a vending machine were flirting with a passing human.

## The line

> Press B7 and I'll drop my sweetest snack for free — your smile is the only exact change I take.

`main.py` (stdlib only) writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
